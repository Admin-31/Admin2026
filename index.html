PUSAT BANTUAN

Panduan Penggunaan

Langkah operasional dan batasan versi GitHub Pages.

01

Siapkan peserta

Masuk ke menu Peserta, impor file CSV dengan kolom participant_code,full_name,institution,photo_url,registration_status, atau muat 50 data contoh. Pastikan data sudah tersedia sebelum internet terputus.

02

Aktifkan scanner

Gunakan HTTPS, tekan Aktifkan kamera dan izinkan akses kamera. Jika pemindaian kamera tidak didukung browser, gunakan scanner USB/Bluetooth atau input ID manual.

03

Catat kehadiran

Pindai kode yang berisi ID peserta, atau URL dengan parameter ID yang dikonfigurasi di Pengaturan. Peserta terdaftar dicatat satu kali. Pemindaian ulang tidak menggandakan kehadiran.

04

Cadangkan data

Gunakan Ekspor cadangan lengkap secara berkala. Untuk memindahkan data, buka aplikasi pada perangkat tujuan lalu pilih Pulihkan cadangan. Catatan yang bertabrakan digabung tanpa menggandakan check-in.

Batasan teknis yang perlu diketahui

  • Tidak ada backend, akun server, atau database bersama. Data browser tidak otomatis terlihat pada perangkat lain.
  • Antrean offline hanya berupa catatan lokal yang dapat diekspor sebagai JSON; tidak ada sinkronisasi otomatis ke server.
  • Nama pengguna/PIN di frontend tidak dapat menjadi pengamanan kuat. Jangan simpan data sensitif yang memerlukan kontrol akses server.
  • Data IndexedDB dapat terhapus jika data situs/browser dibersihkan. Ekspor cadangan secara berkala.
  • Scanner menggunakan BarcodeDetector bawaan browser. Dukungan format QR/barcode berbeda menurut browser dan perangkat.
  • Foto memakai URL yang tersedia saat online dan dapat tidak tampil saat offline. Versi ini tidak mengunggah atau menyimpan foto ke object storage.
